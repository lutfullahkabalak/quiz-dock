# Screenshots

Every shot, in the order of a session: manage your bank and the shared templates, build
the quiz and its media, open the room, players join, questions, reveals, podium, the next
quiz — then the administration of the instance's media. After them, every question type and
slide as the big screen shows it. The README shows a selection.

The media in these shots are free-licensed photos and sounds from Wikimedia Commons,
credited in the app as each licence asks.
